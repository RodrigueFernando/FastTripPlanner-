FastTripPlanner

Aplicativo Android desenvolvido em Kotlin com Jetpack Compose para planejamento de viagens de forma simples e rápida.

---

 Sobre o Projeto

O **FastTripPlanner** permite ao usuário planejar uma viagem informando:

Destino
Número de dias
Orçamento diário

Além disso, o usuário pode escolher:

Tipo de hospedagem
Serviços adicionais

Ao final, o aplicativo calcula automaticamente o custo total da viagem.
